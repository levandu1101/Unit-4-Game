1. BẢNG 7 CÔNG THỨC VIẾT LẠI CÂU KINH ĐIỂN

Mẫu Biến Đổi Công Thức Cặp Tương Đương Ví Dụ Minh Họa
1. similar to ⟷ like S1 + be + similar to + S2
⟷ S1 + be + like + S2		 This portrait is similar to that photo.
➔ This portrait is like that photo.
2. different ⟷ different from S1 and S2 + are different
⟷ S1 + is different from + S2		 Rock and folk are different.
➔ Rock is different from folk.
3. the same [noun] as ⟷ as [adj] as Both are the same size
⟷ A is as big/large as B		 Both puppets are the same size.
➔ The red puppet is as big as the blue one.
4. better than ⟷ not as good as S1 + was better than + S2
⟷ S2 + was not as good as + S1		 The 1st show was better than the 2nd.
➔ The 2nd show was not as good as the 1st.
5. not the same as ⟷ different from S1 + be + not the same as + S2
⟷ S1 + be + different from + S2		 A sculpture is not the same as a painting.
➔ A sculpture is different from a painting.
6. adj-er than ⟷ not as adj as S1 + be + quieter than + S2
⟷ S2 + be + not as quiet as + S1		 The gallery is quieter than the theatre.
➔ The theatre is not as quiet as the gallery.
7. like ... more than ⟷ prefer ... to S + like A more than B
⟷ S + prefer A to B		 I like folk more than pop.
➔ I prefer folk to pop.
